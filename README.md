## Features
- Play MP3 and WAV files  
- Persistent playlists saved in AppData  
- Loop and shuffle tracks  
- Custom installer for Windows via cx_Freeze + Inno Setup  
- Clean, modern UI built with CustomTkinter

---

## Installation
1. Download the installer (`SimplicitiPlayerSetup.exe`) from this release  
2. Run the installer and follow the steps  
3. Launch Simpliciti Player and enjoy your music!

> **Optional:** For advanced users, you can also download the portable cx_Freeze build (`SimplicitiPlayer_v1.0_Win64_cxFreeze.zip`) and run the executable directly.
